Each character should add the following skills for this campaign:

Explore (Wisdom)

Hunting (Wisdom)

Old Lore (Intelligence)

Riddle (Intelligence)

Travel (Wisdom)

By giving up proficiency in a prior skill, you may gain proficiency in one of these.

Please note that skills represent the following substitutions:

Arcana & Religion -> Old Lore

Survival -> Explore, Hunting, & Travel
